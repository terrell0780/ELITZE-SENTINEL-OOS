# Elitze Sentinel Frontier Oos

An AI-first, autonomous enterprise workspace designed to consolidate Go-To-Market strategies, development workflows, and creative studios into a single, high-performance console.

## Overview

Frontier Console is the frontend interface for the Elitze Sentinel network. Modeled with a clean, dark-mode-exclusive, enterprise-grade aesthetic (inspired by Vercel and OpenAI Platform), it strips away clutter in favor of high-density data and functional AI integration.

### Core Modules

- **Platform**: Central intelligence, chat interface, and the 3D Elitze Global Search (powered by MapLibre).
- **Development**: Features the Studio, Code Editor, CLI Terminal, and a multi-pane Code Refactor workspace.
- **Automation**: Manages n8n workflows and Lindy AI autonomous agents.
- **Security**: Threat Intel and Sentinel integrations.
- **Creative**: Image-to-Video generation (integrating with fal.ai patterns) and Media Studios.
- **Business**: A full-stack Apollo.io-inspired Lead Generation tool featuring buyer intent signals and verified trust scores.
- **System**: Co-Build workspaces for multiplayer and solo collaboration, plus settings.

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS (Dark Mode only)
- **Icons:** Custom SVG and lucide-react
- **Maps:** MapLibre GL JS for 3D Earth visualizations
- **TTS:** Native Web Speech API

## Getting Started

### Prerequisites

Ensure you have Node.js and `npm` installed.

### Installation

1. Clone the repository.
2. Install dependencies:
   \`\`\`bash
   npm install
   \`\`\`
3. Run the development server:
   \`\`\`bash
   npm run dev
   \`\`\`
4. Open [http://localhost:3001](http://localhost:3001) with your browser to see the result.

## Design Philosophy

- **Zero Clutter:** No decorative toys, ads, or emojis.
- **High Trust:** Focus on data validity, verified statuses, and clean typography (Inter).
- **Agentic Workflow:** Built to accommodate AI agents running autonomously in the background, not just passive tools.
