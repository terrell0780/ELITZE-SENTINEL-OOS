- **Frontier Chat** — conversational AI with access to the wider platform
- **Executive Brain** — centralized intelligence and decision orchestration
- **Multi-Model AI** — routing across local and cloud models
- **Agent Studio** — build, run, coordinate, and manage autonomous agents
