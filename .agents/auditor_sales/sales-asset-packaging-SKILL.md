# Sales Asset Packaging Runbook

This skill provides step-by-step instructions for packaging high-value domain names and enterprise software codebases for acquisition.

---

## 1. 3-Tier Valuation Model Structure
- **Tier 1: Domain & Brand Asset ($10,000 USD):** Base domain transfer, companion domain, brand asset package.
- **Tier 2: Codebase & Software IP ($25,000 USD):** Tier 1 + 100% source code ownership, application hubs, automated test suite.
- **Tier 3: Turnkey Sovereign AI OS ($35,000 USD):** Tier 1 & 2 + Docker staging setup, Stripe monetization engine, fal.ai video engine, and 30 days direct migration support.

---

## 2. Multi-Channel Copy Generation
Always generate tailored, publication-ready copy for:
- **Acquire.com:** Confidential M&A data room teaser.
- **Flippa:** Auction copy with reserve price ($10k) and BIN ($35k).
- **Indie Hackers:** Founder story and product showcase.
- **Reddit:** Subreddit blueprints (`r/domains`, `r/SideProject`, `r/SaaS`).
- **Dan / Afternic / Sedo:** Buy-Now landing page copy & DNS delegation.

---

## 3. Financial Net Payout Calculator
Calculate net seller payouts taking into account commission fee structures (0% Acquire, 5% Dan lander, 5-10% Flippa, 15% Afternic Fast Transfer).
